# ❤️ Heart Disease Prediction System (Final Year Project)

An end-to-end Machine Learning web application and predictive model built to assess the likelihood of heart disease in patients based on clinical attributes (such as age, blood pressure, cholesterol levels, and ECG results).

## 🚀 Features
* **Exploratory Data Analysis (EDA):** Comprehensive data visualization of feature correlations and distributions.
* **Data Preprocessing:** Handling missing values, feature scaling, and encoding categorical variables.
* **Multiple ML Models:** Implemented and compared models including Logistic Regression, Random Forest, Support Vector Machines (SVM), and Gradient Boosting.
* **Performance Evaluation:** Evaluated using Accuracy, Precision, Recall, F1-Score, and ROC-AUC curves.
* **Interactive Interface:**  Deployed or integrated with a user-friendly frontend interface for real-time predictions.

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python
* **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib, Seaborn
* **Environment:**  Jupyter Notebook
